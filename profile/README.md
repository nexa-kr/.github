<h3 align="center">NEXA</h3>

<p align="center">초대받은 사람만 쓰는 게임 서버 호스팅과 런처</p>

### 공개 저장소

- [**nexa-patches**](https://github.com/nexa-kr/nexa-patches): 운영하면서 만난 모드 크래시·호환 문제를 고치는 패치 모드. 고친 내용은 원작자에게도 알립니다.
